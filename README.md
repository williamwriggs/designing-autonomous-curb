# Designing the Autonomous Curb

Research archive for the paper:

**Designing the Autonomous Curb: Evidence from Interviews and Synthetic Pick-Up and Drop-Off Activity for Informed Urban Design of the Built Environment**

## Contents

- `data/synthetic_av_pudo_events.csv` — 4,080 synthetic passenger pick-up and drop-off events used in the spatial and temporal analyses.
- `data/data_dictionary.csv` — field definitions for the synthetic dataset.
- `manuscript/` — manuscript and publication files.
- `figures/` — publication figures in archival formats.
- `docs/METHODS_AND_LIMITATIONS.md` — reproducibility and interpretation notes.
- `CITATION.cff` — citation metadata.

## Important data note

The archived event data are **synthetic data**, not raw commercial operating records. They preserve generalized spatial and temporal characteristics used for exploratory planning analysis and should not be interpreted as a definitive measure of any operator’s behavior across San Francisco.
